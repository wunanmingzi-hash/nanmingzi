# 可编辑制作与验收

在可编辑试制、图片重构或完整 PPTX 制作前读取。视觉相似、对象可编辑和目标应用兼容是不同要求，需要分别检查。

## 内容与视觉基准

确认文字稿与原始数据提供内容，确认视觉稿提供构图、层级和风格。在内容准确和约定编辑能力满足后尽量接近视觉稿。“1:1”是高保真目标，不代表像素完全相同。

禁止把整页参考图、含文字或图表的局部复合截图、隐藏的参考图或透明文字覆盖截图放入正式文件冒充重构。照片、艺术插画、保真标识和经确认允许的纯装饰图片可以作为独立素材；正文、数据和信息关系不能归为装饰。

## 对象标准

| 对象 | 制作要求 | 编辑验证 |
|---|---|---|
| 标题、正文、注释和标签 | 原生文本，按段落或语义分框 | 修改文字和字体，检查换行 |
| 表格 | 原生表格，保留行列和单元格 | 修改单元格及样式 |
| 数据图表 | 使用可修改数据的原生图表，保留轴、单位、图例和标签 | 修改一个数值，确认图形随数据更新 |
| 流程、时间轴和关系图 | 原生节点、文字与必要连接线 | 移动节点并检查连接和层级 |
| 色块、边框、线条和背景 | 原生形状或页面填充 | 修改颜色、大小和位置 |
| 图标和主要装饰 | 按自然结构重建为合理数量的形状并分组 | 修改约定部件与分组 |
| 照片、艺术插画和标识 | 使用独立原始素材，保持比例 | 可独立替换、移动和裁切 |

用形状模拟柱形和标签不等于数据驱动图表。能力不足时说明具体差异并选择替代方案，不能静默降低编辑能力。SVG 作为图像插入时只代表可缩放；需要逐部件编辑时必须在目标应用验证转换为形状，正文和标签仍用原生文本。

## 字体、复杂效果与外部依赖

- 优先使用已验证字体；替代时选择字形、字宽和字重接近的字体，并检查整套换行。未经实际检查不声称字体已嵌入或跨设备一致。
- 光效、水墨、颗粒和复杂透明叠加等效果先在高风险试制页验证。无法同时保持外观与细粒度编辑时，说明原生近似、简化设计或独立装饰图片的实际差异。
- 外部图片保留来源；Logo 使用用户提供的原始资产。视频、音频、字体、链接和外部数据说明嵌入或依赖关系，并在实际交付环境检查。
- 相关对象按语义分组，重复页脚、页码和样式按工具能力使用母版或统一样式；不要把正文、图表和装饰合成一个难编辑的大组。

## 试制与检查

试制选择风险最高的 1—2 页，交付可打开的 PPTX、渲染预览、字体替代、独立图片及明显差异。在测试副本中实际完成适用操作：

1. 修改标题并加入少量文字，检查换行。
2. 修改已有图表数据或表格单元格，检查对象随之变化。
3. 移动一组对象；存在流程节点时检查连接线。
4. 保存、关闭、重新打开并渲染，确认修改保留且文件无需修复。

试制确认后复用已通过的字体、文本框划分、对象分组、图表和装饰处理。完整文件至少完成以下检查：

- **内容：** 页数、顺序、文案、数字、单位、期间、图例、引用和结论对应正确，没有占位文字或版本混用。
- **视觉：** 渲染整套并检查层级、字体替代、溢出、遮挡、裁切、图片比例、图表标签、对齐、配色和背景；缩略总览检查风格漂移。
- **对象：** 文字、表格、图表和图形符合约定编辑标准，不存在未约定的整页或局部复合截图。新增对象类型补做相应编辑试验。
- **兼容：** 只有实际在目标应用打开并检查后，才能声称通过该应用验证；库内渲染和对象解析不能代替 PowerPoint 或 WPS 检查。

缺少目标应用或编辑能力时，完成可执行检查并列出未验证项。已知影响准确性、正常打开或约定编辑能力的问题应先修复，或取得用户对具体替代方案的选择。

最终交付完整 PPTX，并简要列出字体替代、允许的图片素材、外部依赖和未验证项。测试副本、临时截图与内部记录不进入正式交付包。
